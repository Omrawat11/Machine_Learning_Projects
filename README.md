## 📌 About

This repository is a growing collection of **machine learning projects and mini-experiments**, covering supervised learning, ensemble methods, and clustering. Each folder is a self-contained project with its own dataset, notebook, and (where applicable) a trained model — built while exploring different algorithms, problem types (regression / classification / clustering), and real-world datasets.

Think of this repo as a **personal ML playground and portfolio log** — a mix of polished mini-projects and learning notebooks.

---

## 🗂️ Projects Included

| Project | Type | Description |
|---|---|---|
| 💎 **Diamond Price Prediction** | Regression | Predicts diamond prices based on features like carat, cut, color, and clarity. |
| 🧠 **Stroke Prediction** | Classification | Predicts the likelihood of a stroke based on health and lifestyle attributes. |
| ⚡ **AdaBoost** | Ensemble Learning | Implementation/experiments using the AdaBoost boosting algorithm. |
| 🔥 **Calories Burn Prediction** | Regression | Predicts calories burned during exercise using physiological features. |
| 🏋️ **Gym Membership** | Classification/EDA | Analysis and prediction related to gym membership data. |
| 🌳 **Hierarchical Clustering** | Unsupervised Learning | Notebook demonstrating hierarchical clustering concepts and dendrograms. |

> More projects are added over time as new concepts are explored.

## 🚀 Getting Started

1. Clone the repository
   ```bash
   git clone https://github.com/Omrawat11/Machine_Learning_Projects.git
   cd Machine_Learning_Projects
   ```
2. Install common dependencies
   ```bash
   pip install numpy pandas scikit-learn matplotlib seaborn jupyter
   ```
3. Open any project folder and launch its notebook
   ```bash
   jupyter notebook
   ```
